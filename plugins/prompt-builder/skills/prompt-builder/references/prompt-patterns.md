# Prompt Patterns

Use these as ingredients, not required forms. Omit any sentence that does not change the work.

## General

```text
Create <result> for <audience or intended use>. Use <relevant context or sources>. Return <format or level of detail>. Keep <important boundary> unchanged. Before finishing, check <specific failure condition>.
```

## Code Change

```text
Implement <behavior> in <scope>. The current behavior or reproduction is <details>. Preserve <important constraint>. Verify the change with <specific check> and report the result.
```

## External Action

```text
Prepare <message, publication, deployment, purchase, or other action> for review using <sources>. Do not <send, publish, deploy, purchase, or change shared information>. Check <specific condition> and show what is ready for approval.
```
